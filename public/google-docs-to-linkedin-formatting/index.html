The Problem

When you copy text from Google Docs and paste it into LinkedIn, all the formatting is lost. Bold becomes regular text. Italic disappears. There is no way to paste formatted content into LinkedIn posts.

This is because LinkedIn only accepts plain text. Google Docs formatting (font sizes, colors, styles) cannot be preserved when pasting to LinkedIn.

The Solution: Unicode Text

Unicode includes mathematical bold, italic, and script characters. LinkedOut detects bold and italic formatting from Google Docs paste and converts it to Unicode equivalents that LinkedIn can display.

What LinkedOut Detects From Google Docs

  • B Bold text — detected from Ctrl+B or the B button
  • I Italic text — detected from Ctrl+I or the I button
  • S Strikethrough text — detected from Format menu or keyboard shortcut
  • T Inline code — detected from code blocks
